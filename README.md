# 🧮 Age Calculator

A simple Python project that calculates a person's current age based on their date of birth.

## 📌 Features

* Takes the user's date of birth as input
* Calculates the current age
* Uses the current date automatically
* Simple and beginner-friendly

## 🛠️ Technologies Used

* Python
* `datetime` module

## ▶️ How It Works

1. Enter your birth year.
2. Enter your birth month.
3. Enter your birth day.
4. The program calculates and displays your current age.

* Date Handling
* Basic Calculations
